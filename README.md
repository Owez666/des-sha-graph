# Ветка docker
Ветка `docker` содержит конфигурацию для сборки и запуска сервера проекта  
**des-sha-graph** в контейнере **Docker** на базе **Ubuntu 20.04**.  

Проект реализует сервер с поддержкой:
- Регистрации и авторизации пользователей (через **SQLite**);
- Обработки команд (`ping`, `register`, `login` и т.д.);
- Подключения нескольких клиентов одновременно;
- Паттерна **Singleton** для работы с базой данных.
---

##  Содержимое ветки
- `Dockerfile` — инструкция для сборки контейнера  
- `.dockerignore` — исключает лишние файлы при копировании  
- Исходные файлы проекта:
  - `main.cpp`
  - `mytcpserver.cpp`
  - `mytcpserver.h`
  - `databasemanager.cpp`
  - `databasemanager.h`
  - `echoServer.pro`

## Запуск контейнера

После сборки можно запустить сервер командой:

```docker run -d -p 33333:33333 -v ./data:/app/data des-sha-graph```

## Итог: 
В результате работы была выполнена успешная контейнеризация проекта des-sha-graph. Созданный образ содержит полностью настроенное окружение для запуска сервера, включая все необходимые зависимости (Qt, SQLite, g++) на базе Ubuntu 20.04.

После сборки контейнера сервер корректно запускается, открывает базу данных и обрабатывает запросы клиентов. Подключение через PuTTY к порту 33333 подтверждает работоспособность всех функций — регистрация, авторизация, обработка команд и взаимодействие с базой данных.

### Docker обеспечивает:

1. Изолированное и переносимое окружение для Qt-приложения
2. Быстрый запуск без дополнительной настройки системы
3. Возможность разворачивания проекта на любой машине с установленным Docker
4. Проверенную работоспособность многопользовательского сервера
